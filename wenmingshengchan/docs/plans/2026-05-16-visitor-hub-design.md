# 设计文档：访客大厅 (Visitor Hub) 页面设计

## 1. 背景与目标
为了符合微信小程序运营规范第 3.4 条（禁止强制登录），我们需要重新设计小程序的启动流程。
**核心目标**：
1.  **合规性**：允许用户在未登录状态下浏览系统核心价值和公共信息。
2.  **业务引导**：通过展示“日计划”、“报备”、“重点工作”三大核心功能，吸引潜在用户（现场工友、管理人员）入驻。
3.  **无缝体验**：对于已登录用户，通过自动重定向技术实现“无感”进入工作台。

## 2. 页面结构设计 (pages/index/visitor)

### 2.1 工业品牌 Hero 区域
*   **视觉**：深色工业质感背景 + 科技感网格线。
*   **文案**：文明生产生产管理系统。
*   **状态标示**：顶部显示“访客模式”，右侧带有“环境监测：正常”等模拟工业状态位。

### 2.2 三大核心支柱模块 (High-Profile Features)
此区域为本次设计的重中之重，采用 **Bento Grid（便当盒布局）** 或 **三纵列大卡片**。
1.  **日计划执行 (Daily Plan)**
    *   **图标**：日历/任务列表。
    *   **描述**：任务精细化分配，每日施工节点一目了然。
    *   **预览**：展示一个模拟的“今日任务进度条”。
2.  **问题安全报备 (Safety Reporting)**
    *   **图标**：警示灯/相机。
    *   **描述**：隐患随时拍，问题即刻办，打造现场安全闭环。
    *   **预览**：展示最近一条“已解决”的真实公示记录。
3.  **重点工作推进 (Key Projects)**
    *   **图标**：旗帜/工程塔吊。
    *   **描述**：重大项目进度全方位跟踪，各级响应透明化。
    *   **预览**：展示“正在推进中”的项目数量统计。

### 2.3 现场实时看板 (Live Feed)
*   **轮播图**：展示现场最新的实拍照片。
*   **信息流**：展示最近的“信息公告”标题滚动。

### 2.4 操作引导
*   **底部固定栏**：一个极具视觉吸引力的按钮：“**进入我的工作台**”。
*   **交互逻辑**：点击卡片或按钮时，系统会优雅地提示：“当前功能需身份验证，请前往登录/注册”。

## 3. 技术方案与流程控制

### 3.1 启动分流逻辑
1.  在 `pages/index/visitor.vue` 的 `onLoad` 生命周期函数中：
    *   调用 `vk.getVuex('$user.userInfo')` 检查登录态。
    *   若已登录且具有效 Token，立即调用 `uni.reLaunch({ url: '/pages/index/index' })` 跳转到正式首页。
    *   若未登录，则渲染访客大厅内容。

### 3.2 数据请求安全性
*   访客页面的请求需调用公共或无权限限制的云函数接口（如 `client/info/pub/getList`）。
*   若接口为 `kh`（需登录）接口，则需在云端处理：未登录时返回空列表而非报错，以保证页面渲染稳定。

### 3.3 路由管理
*   修改 `pages.json`，将 `pages/index/visitor` 设为数组首位。
*   将原有的 `pages/user/login/index` 调整为次要路径。

## 4. 视觉风格定义
*   **主色调**：#0050cb (工业蓝)。
*   **辅助色**：#dc2626 (安全红 - 用于报备)、#16a34a (进度绿 - 用于日计划)。
*   **字体**：Inter / Manrope (现代技术感字体)。
