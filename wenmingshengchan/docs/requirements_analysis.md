# 文明生产专业管理系统 完整版需求分析文档

**适配场景**：微信小程序 UI/UX 设计（Stitch 生成）+ 前后端开发**技术规范**：Vue2 + VK UniCloud Router + 阿里云 UniCloud + vk-fun技能。

1、系统建立目标。
建立文明生产专业管理系统，主要功能是落实现场点位状态监管、文明生产计划执行管理、文明生产专业信息管理、现场问题报备管理。
2、技术栈。
Vue 2 + VK UniCloud Router + UniCloud(阿里云) ，所有涉及UniCloud操作全部要使用vk-fun技能实现。
3、项目结构：
前端使用小程序、后端使用web系统。结构如下：
projectStructure:
  modules:
    client:
      name: "微信小程序(mp-client)"
      rootPath: "./mp-client"
      description: "小程序页面，包含展示、交互、用户操作等功能，所有的页面路径规则等参考https://vkdoc.fsq.pub/client/changelog.html"
    admin:
      name: "后台管理(mp-admin)"
      rootPath: "./mp-admin"
      description: "管理后台，包含数据管理、权限控制、配置管理等功能，所有的页面路径规则等参考https://vkdoc.fsq.pub/admin/1/catalogue.html"
    unicloud:
      name: "Unicloud云函数"
      rootPath: "./mp-client/uniCloud-aliyun/cloudfunctions/router/service"
      description: "云函数、数据库配置、接口逻辑等服务端功能，其中前台云函数在client文件夹内，后台云函数在admin文件夹内，每个功能模块的云函数都在对应的文件夹内，所有的云函数命名和书写规则参考https://vkdoc.fsq.pub/client/uniCloud/cloudfunctions/catalogue.html。 "



## 1. 基础数据管理需求

### 1.1 用户管理需求

- 功能描述：基于微信授权实现用户登录、信息完善、管理员审核，构建系统身份认证体系，为所有业务功能提供权限基础。
- 端侧功能（C 端 / 前台）：
1. **微信授权登录操作流程**：打开小程序→自动唤起微信授权弹窗→用户同意授权→获取微信头像 / 昵称→系统校验用户信息：首次用户跳转注册页，老用户校验是否完善信息，未完善强制跳转注册页，已完善且审核通过直接进入首页；未审核用户跳转未审核提示页。
2. **用户信息完善操作流程**：注册页展示不可编辑的微信头像 / 昵称→填写真实姓名、手机号→通过两级级联选择器选择「部门→小组」→点击提交注册→提交成功后等待管理员审核，页面显示审核提示。
3. **我的页面操作流程**：底部 Tab 进入「我的」→顶部展示个人信息卡片（头像、姓名、部门、审核状态）→下方提供 4 个功能入口（卡片标题为操作记录查询）：[现场反馈信息]、[计划执行信息]、[重点工作信息]、[问题报备信息]→点击入口跳转对应二级页面→底部支持退出登录。
4. **页面约束**：未审核用户仅能查看提示页，无法访问任何业务功能；审核通过用户解锁全部操作权限。
- 管理功能（B 端 / 后台）：
1. 用户列表以表格展示：头像、微信昵称、真实姓名、手机号、部门、角色、审核状态、注册时间，支持分页、模糊搜索、状态筛选。
2. 左侧展示部门 - 小组树形筛选器，部门管理员仅可见本部门用户，超级管理员可见全部用户。
3. 支持单用户 / 批量用户审核（通过 / 拒绝）、编辑用户信息、禁用账号操作。
- 权限约束：
1. 普通用户：仅可完善个人信息、查看本人资料、使用业务功能，无管理权限。
2. 部门管理员：查看 / 审核本部门及小组用户，无跨部门操作权限。
3. 超级管理员：全系统用户管理、审核、编辑、禁用权限。
- 技术组件：

- 微信授权登录：vk.userCenter.loginByWeixin组件

- 信息表单：表单组件

- 部门选择：级级联选择器

- 接口服务：unicloud云函数（严格使用vk-fun技能书写）、uni-id 用户体系

- 登录校验：loginFilter 中间件

- 路径 / 配置约束：

- C 端页面：`./mp-client/pages/user/`（登录页、注册页、我的页面、信息审核提示页）

- B 端页面：`./mp-admin/pages/baseinfo/user/list.vue`

- 云函数：`./router/service/client/user/`、`./router/service/admin/baseinfo/user/`

- 数据库：`../../database/uni-id-users.schema.json`

### 1.2 部门管理需求

- 功能描述：维护公司 - 部门 - 小组三级组织架构，为用户归属、业务责任划分提供基础数据，其中公司级仅做后台树形展示，不纳入各功能页面级联数据中。
- 端侧功能（C 端 / 前台）：无独立页面，仅为用户注册提供级联选择数据源，采用二级级联数据。
- 管理功能（B 端 / 后台）：
1. 部门列表页展示：左侧为部门信息，包括部门名称、负责人等，选中部门后，右侧展示部门对应的小组信息，包括小组名称、负责人、备注、启用状态，支持新增、编辑、删除、查询。
2. 固定顶级节点为「马城矿业公司」，二级为部门，三级为小组，树形结构管理。
3. 已关联用户的部门禁止删除，仅可禁用；禁用部门自动屏蔽下级小组。
- 权限约束：
1. 部门管理员：无操作权限，仅可查看。
2. 超级管理员：全权限管理三级组织架构。
- 技术组件：树形组件、表格组件。

- 路径 / 配置约束：

- B 端页面：`./mp-admin/pages/baseinfo/dept/list.vue`

- 云函数：`./router/service/admin/baseinfo/dept/`

- 数据库：`../../database/base-dept.schema.json`

### 1.3 作业区域管理需求

- 功能描述：维护生产现场作业区域基础数据，作为作业点位的上级归属载体。
- 端侧功能（C 端 / 前台）：无独立页面，仅为后台配置提供数据支撑。
- 管理功能（B 端 / 后台）：
1. 作业区域列表展示：区域名称、负责部门、备注、状态，支持增删改查、分页查询。
2. 新增 / 编辑时关联负责部门，禁用区域不参与作业点位绑定。
- 权限约束：仅超级管理员拥有全部操作权限。

- 技术组件：表格组件、云函数

- 路径 / 配置约束：

- B 端页面：`./mp-admin/pages/baseinfo/area/list.vue`

- 云函数：`./router/service/admin/baseinfo/area/`

- 数据库：`../../database/base-area.schema.json`

### 1.4 作业点位管理需求

- 功能描述：维护作业区域下的具体生产点位，是重控点位监督的核心基础数据。
- 端侧功能（C 端 / 前台）：无独立页面，为点位反馈提供数据支撑。
- 管理功能（B 端 / 后台）：
1. 作业点位列表展示：点位名称、隶属区域、负责部门、备注、状态，支持增删改查。
2. 新增 / 编辑时通过级联选择器绑定作业区域，自动同步负责部门。
3. 已配置为重控点位的记录禁止删除，仅可编辑状态。
- 权限约束：仅超级管理员拥有全部操作权限。

- 技术组件：级联选择器、表格组件、vk-fun 云函数

- 路径 / 配置约束：

## 2. 重控点位监督管理需求

### 2.1 重控点位配置与反馈需求

- 功能描述：建立点位与责任人的绑定关系，用户每班完成现场反馈，实现重控点位常态化监管。
- 端侧功能（C 端 / 前台）：
1. **首页待反馈展示操作流程**：审核通过用户进入首页→顶部自动加载当日待反馈重控点位数量卡片→点击卡片进入待反馈列表页。
2. **待反馈列表操作流程**：列表仅展示当前用户负责的点位→显示点位名称、所属区域、反馈状态→点击点位进入反馈录入页。
3. **反馈录入操作流程**：页面展示点位基础信息→上传 1 张主现场照片 + 最多 5 张补充照片→富文本编辑器填写现场情况→点击提交→提交成功后当日该点位不可重复反馈（其他用户也不行）→自动返回列表页。
4. **历史查询操作流程**：「我的」页面进入现场反馈历史→列表展示所有历史反馈记录→点击记录查看详情（照片、内容、提交时间）。
5. 核心逻辑：

```
今天是4月4日，那么规则：4月4日的夜班是4月3日20:00-4月4日8:00，4月4日白班是4月4日8:00-20:00。
现在我需要做一个系统，功能：
1、配置用户与工作区域关系，要求每班都要有现场照片反馈。
2、要求每个班结束前1小时，以及班后2小时内上传本班现场的照片，提前、过期都不能上传。
3、系统要读取本班是否上传照片，采用逻辑查询？
4、为了提供更好的服务，系统要自动显示需要录入的反馈，如何筛选。
请帮我设计系统以及系统操作流程。
```

- 管理功能（B 端 / 后台）：
1. 重控点位配置：选择作业区域、点位，批量绑定用户 / 部门 / 小组，生成反馈任务。
2. 反馈数据管理：按日期、部门、点位筛选反馈记录，查看现场照片、反馈内容，标记问题、回复处理结果。
3. 数据统计：自动统计每日点位反馈完成率、问题发生率。
- 权限约束：
1. 普通用户：仅提交本人负责点位的反馈，查看本人历史记录。
2. 部门管理员：管理本部门点位配置，查看本部门所有反馈数据。
3. 超级管理员：全系统配置、管理、统计权限。
- 技术组件：

- 内容编辑：富文本编辑器

- 列表加载：下拉刷新 + 上拉加载组件

- 接口服务：vk-fun 云函数

- 路径 / 配置约束：

- C 端页面：`./mp-client/pages/feedback/`（首页待反馈模块、待反馈列表页、反馈录入页、历史查询页）

- B 端页面：`./mp-admin/pages/feedback/point-config.vue`、`feedback-list.vue`

- 云函数：`./router/service/client/feedback/`、`./router/service/admin/feedback/`

- 数据库：`../../database/key-point-config.schema.json`、`key-point-feedback.schema.json`

## 3. 重点项目管理需求

- 功能描述：实现重点项目创建、过程反馈、验收申请、管理员批复的全闭环管理。
- 端侧功能（C 端 / 前台）：
1. **项目列表操作流程**：首页进入重点项目模块→列表展示本人负责的项目（进行中 / 待验收 / 已完成）→显示项目名称、标准、负责人、状态、截止时间。
2. **过程反馈操作流程**：选择进行中项目→填写项目进展、上传佐证照片→提交过程反馈→同步至后台。
3. **验收申请操作流程**：项目完成后提交验收申请→填写验收说明、上传成果材料→等待管理员批复→批复结果实时推送至小程序。
- 管理功能（B 端 / 后台）：
1. 项目创建：填写项目信息（包括项目名称、区域、点位、执行标准、完成时限），指定多名负责用户，设置项目周期。
2. 批复管理：查看验收申请，执行「通过 / 驳回」操作，驳回需填写原因。
3. 项目管理：编辑项目信息、关闭已完成项目、按部门统计项目进度。
- 权限约束：
1. 普通用户：仅反馈本人负责项目，查看批复结果。
2. 部门管理员：管理本部门重点项目。
3. 超级管理员：全系统项目管理权限。
- 技术组件：富文本编辑器、vk-fun 云函数

- 路径 / 配置约束：

- C 端页面：`./mp-client/pages/keywork/project/`（项目列表页、过程反馈页、验收申请页、结果查看页）

- B 端页面：`./mp-admin/pages/keywork/project-list.vue`

- 云函数：`./router/service/client/keywork/`、`./router/service/admin/keywork/`

- 数据库：`../../database/key-project.schema.json`

## 4. 日治理计划管理需求

- 功能描述：各单位提交日常治理计划，指定用户执行，并反馈完成情况，按单位 + 日期归集展示执行结果。
- 端侧功能（C 端 / 前台）：
1. **计划查询操作流程**：首页进入日治理计划模块→列表展示本单位，且需要本人执行的当日待完成计划→显示计划名称、执行内容、负责部门、负责人、截止时间。
2. **完成反馈操作流程**：选择计划→填写完成情况、上传现场佐证材料→提交反馈→系统标记计划已完成。
3. **历史统计操作流程**：「我的」页面进入计划执行历史→按日期筛选历史记录→查看计划完成详情。
- 管理功能（B 端 / 后台）：
1. 计划发布：创建日治理计划，指定负责单位 / 用户，设置执行要求。
2. 数据归集：按单位、日期自动归集计划完成情况，查看反馈详情、审核完成质量。
3. 报表导出：导出日治理计划执行统计报表。
- 权限约束：
1. 普通用户：反馈本人负责的计划完成情况。
2. 部门管理员：管理本部门计划，查看执行数据。
3. 超级管理员：全系统计划管理与统计。
- 技术组件：日期选择器、uni-upload 组件、vk-fun 云函数

- 路径 / 配置约束：

- C 端页面：`./mp-client/pages/plan/`（计划列表页、完成反馈页、历史统计页）

- B 端页面：`./mp-admin/pages/plan/plan-list.vue`

- 云函数：`./router/service/client/plan/`、`./router/service/admin/plan/`

- 数据库：`../../database/daily-plan.schema.json`

## 5. 专业信息传达管理需求

### 5.1 信息分类与发布管理需求

- 功能描述：管理员发布专业管理信息，用户分类浏览查看，系统自动记录浏览轨迹。
- 端侧功能（C 端 / 前台）：
1. **信息中心操作流程**：底部 Tab 进入「信息中心」→顶部展示可横向滑动的分类 Tabs→默认选中全部分类→下拉加载信息列表→每条信息展示标题、发布时间、浏览量。
2. **详情查看操作流程**：点击信息标题→进入 Markdown 详情页→查看全文→系统自动记录浏览人 + 浏览时间→支持页面上下滑动。
- 管理功能（B 端 / 后台）：
1. 信息分类管理：新增 / 编辑 / 删除分类，设置排序码、状态，禁用分类不展示在小程序。
2. 信息发布：使用 cherry-markdown 编辑器编写内容，关联分类，设置发布 / 下架状态。
3. 数据统计：信息列表展示浏览次数、浏览人列表，支持下架、删除操作。
- 权限约束：
1. 普通用户：仅浏览查看信息，无编辑权限。
2. 超级管理员：全权管理分类与信息发布。
- 技术组件：

- 后台编辑：cherry-markdown 编辑器

- 前台展示：markdown-viewer 组件

- 分类切换：横向滑动 Tabs 组件

- 路径 / 配置约束：

- C 端页面：`./mp-client/pages/info/`（信息中心页、信息详情页）

- B 端页面：`./mp-admin/pages/info/category-list.vue`、`info-list.vue`

- 云函数：`./router/service/client/info/`、`./router/service/admin/info/`

- 数据库：`../../database/info-category.schema.json`、`info.schema.json`

## 6. 报备信息管理需求

- 功能描述：用户匿名提交现场问题，管理员审核回复，问题匿名公示，形成问题闭环处理。
- 端侧功能（C 端 / 前台）：
1. **问题提交操作流程**：「我的」页面进入问题报备提交页→填写问题标题→富文本编辑器填写问题详情→点击匿名提交→提交成功后隐藏个人信息→自动跳转公示页。
2. **公示查看操作流程**：报备公示页列表匿名展示所有问题→显示标题、提交时间、回复状态→点击问题展开展开详情与管理员回复内容。
3. **个人查询操作流程**：「我的」页面进入报备信息查询→查看本人提交的所有报备记录、处理进度、回复内容。
- 管理功能（B 端 / 后台）：
1. 报备审核：列表展示所有问题，执行审核、回复、归档操作。
2. 回复同步：管理员回复内容实时同步至小程序公示页，标记已解决问题。
- 权限约束：
1. 普通用户：匿名提交问题、查看公示、查询本人记录。
2. 部门管理员：处理本部门相关报备问题。
3. 超级管理员：处理全系统所有报备问题。
- 技术组件：富文本编辑器、vk-fun 云函数

- 路径 / 配置约束：

- C 端页面：`./mp-client/pages/report/`（报备提交页、公示页、个人查询页）

- B 端页面：`./mp-admin/pages/report/report-list.vue`

- 云函数：`./router/service/client/report/`、`./router/service/admin/report/`

- 数据库：`../../database/problem-report.schema.json`
