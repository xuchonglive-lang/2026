# 功能说明书：培训业务模块

**功能分支**: `training-module`
**创建日期**: 2026-03-13
**状态**: 草案
**优先级**: P3
**输入**: 办公应用平台需求文档 - 第5章 培训业务模块
**依赖模块**: 租户管理（tenant）、权限管理（permission）、消息管理（message）

> **宪法合规声明**: 本提案严格遵守项目宪法。云函数遵循 `vk-fun` 技能规范，前端遵循 UI/UX Pro Max 全局规范，前台遵循 PC+H5 自适应布局规范。Markdown渲染使用全局 `MarkdownViewer.vue`（markdown-it + markdown-it-toc-done-right），视频播放使用 **Video.js**，后台编辑器使用 **cherry-markdown**，留言使用 **Artalk 组件**，浏览记录使用 **history-manager-component 组件**。
> **UI/UX 规则注入位置**: 功能描述后、操作要求前。

## 用户场景与测试 *(必填)*

### 用户故事 1 - 培训首页浏览 (优先级: P1)

用户进入培训首页（`xc/pages/training/list.vue`），顶部搜索栏支持关键词搜索，下方分类 tab（全部/视频课程/文章课程/我的课程），主区域展示课程卡片列表。PC端采用网格布局（每行3张卡片，卡片间距24px），H5端采用单列卡片布局。每张卡片包含：封面图（16:9 比例）、标题（最多2行，超出省略）、发布部门标签、观看人数+时长/字数。支持下拉刷新+上拉加载。

**优先级理由**: 培训首页是用户进入培训模块的第一触点。

**独立测试**: 创建不同类型的课程，验证列表展示和筛选功能。

**验收场景**:

1. **假设** 系统中有 5 门视频课程和 3 门文章课程，**当** 用户进入培训首页（默认"全部"tab），**那么** 显示 8 张课程卡片，按发布时间倒序
2. **假设** 用户切换到"视频课程"tab，**当** 列表刷新，**那么** 仅显示 5 门视频课程，卡片右下角显示"总时长: 2h30m"
3. **假设** 用户切换到"文章课程"tab，**当** 列表刷新，**那么** 仅显示 3 门文章课程，卡片右下角显示"约 5000 字"
4. **假设** 用户切换到"我的课程"tab，**当** 列表刷新，**那么** 仅显示用户有观看记录的课程，每张卡片底部显示学习进度条（如 "已学习 60%"）
5. **假设** 用户在搜索栏输入"安全"并搜索，**当** 搜索执行，**那么** 列表过滤显示标题含"安全"的课程
6. **假设** PC端浏览器窗口宽度 > 768px，**当** 页面渲染，**那么** 课程卡片采用3列网格布局（`grid-template-columns: repeat(3, 1fr)`）
7. **假设** H5端或窗口宽度 < 768px，**当** 页面渲染，**那么** 课程卡片采用单列布局，卡片宽度100%

### 用户故事 2 - 视频课程详情页 (优先级: P1)

用户点击视频课程卡片进入详情页（`xc/pages/training/video-detail.vue`）。PC端布局：顶部视频播放区域（左侧章节列表 + 右侧播放器），视频下方显示课程标题、发布部门、发布时间、观看次数，再下方 tab 切换（课程简介/章节目录/附件下载/留言互动）。H5端布局：视频播放器全宽置顶，下方课程信息 + tab区域。

**优先级理由**: 视频课程是培训的核心内容形式。

**独立测试**: 播放视频、切换章节、查看附件、发布留言。

**验收场景**:

1. **假设** 视频课程有3个章节，**当** 用户进入详情页，**那么** PC端左侧显示章节列表（序号+标题+时长），默认选中第一章节，右侧播放器加载第一章节视频
2. **假设** 用户点击第二章节，**当** 章节切换，**那么** 播放器加载第二章节视频，章节列表高亮当前章节（左边框 3px 主色）
3. **假设** 单视频模式课程（仅一个视频），**当** 进入详情页，**那么** 不显示章节列表，播放器全宽显示
4. **假设** 用户切换到"附件下载"tab，**当** 显示附件列表，**那么** 使用全局 `AttachmentList.vue` 组件展示，每个附件显示：文件图标、文件名、大小、下载按钮
5. **假设** 用户切换到"留言互动"tab，**当** 显示留言区，**那么** 使用全局 `CommentSection.vue` 组件，显示留言列表（时间倒序）+ 底部留言输入框
6. **假设** 当前视频课程用户无权限查看（`visibility=targeted` 且用户不在目标部门），**当** 用户访问详情页，**那么** 显示无权限提示"您没有查看此课程的权限"

### 用户故事 3 - 文章课程详情页 (优先级: P1)

用户点击文章课程卡片进入详情页（`xc/pages/training/article-detail.vue`）。PC端布局：左侧悬浮目录导航（markdown-it-toc-done-right 生成，sticky 定位），右侧文章正文（markdown-it 渲染），正文下方附件栏 + 留言互动区。H5端布局：目录折叠为顶部下拉按钮。

**优先级理由**: 文章课程是培训的另一核心内容形式。

**独立测试**: 查看文章、目录导航跳转、附件下载、发布留言。

**验收场景**:

1. **假设** 文章课程内容含多个 h2/h3 标题，**当** 页面渲染，**那么** 左侧目录导航自动生成，点击目录项滚动到对应位置，滚动时目录高亮当前可视区域对应的标题
2. **假设** H5端用户查看文章，**当** 页面加载，**那么** 目录导航不在左侧显示，页面顶部出现"📖 目录"按钮，点击展开为下拉式目录列表
3. **假设** 文章课程含附件，**当** 滚动到文章正文底部，**那么** 正文下方显示附件栏（`AttachmentList.vue`）和留言互动区（`CommentSection.vue`）

### 用户故事 4 - 课程观看记录与学习进度 (优先级: P2)

系统自动记录用户的课程学习进度。视频课程记录每个章节的播放时长和进度百分比，文章课程记录是否已阅读完毕（滚动到底部视为已读）。"我的课程"中显示学习进度条。

**优先级理由**: 学习进度跟踪是培训管理的核心指标。

**独立测试**: 用户观看视频暂停后离开，再次进入时恢复到上次播放位置。

**验收场景**:

1. **假设** 用户观看视频课程第一章节播放到 5 分钟（共 10 分钟），**当** 用户离开页面，**那么** 系统记录当前进度（`chapter_id`, `play_duration: 300`, `progress: 50`），5秒间隔自动保存一次
2. **假设** 用户再次进入同一课程，**当** 页面加载，**那么** 弹出提示"上次观看到 05:00，是否继续？"，确认后视频跳转到 5:00 位置
3. **假设** 用户阅读文章课程并滚动到底部，**当** 触发底部检测事件，**那么** 系统标记该文章为"已阅读"
4. **假设** 课程有 3 个章节，用户完成了 2 个章节，**当** 在"我的课程"列表查看，**那么** 显示进度条 67%（2/3）

### 用户故事 5 - 后台课程管理 (优先级: P1)

管理员在后台课程管理页（`xc-admin/pages/training/list.vue`）管理所有课程。列表使用 `vk-data-table`，支持按类型/状态/部门筛选和搜索。

**优先级理由**: 课程管理是培训模块的运营基础。

**独立测试**: 创建/编辑/发布/下架课程的全流程。

**验收场景**:

1. **假设** 管理员打开课程管理页，**当** 页面加载，**那么** `vk-data-table` 显示课程列表，列包含：标题、类型标签（视频/文章）、发布部门、状态标签（草稿=灰/已发布=绿/已下架=红）、观看人数、创建时间、操作列
2. **假设** 管理员点击"新建视频课程"进入编辑页（`xc-admin/pages/training/edit.vue`），**当** 页面加载，**那么** 左侧步骤导航（基本信息→章节管理→附件上传→可见性设置），右侧对应表单区域
3. **假设** 基本信息表单包含：标题（必填）、封面图上传（必填，16:9）、课程简介（Markdown编辑器）、分类选择，**当** 管理员填写完毕点击"下一步"，**那么** 进入章节管理步骤
4. **假设** 章节管理区域，**当** 管理员点击"添加章节"，**那么** 新增一行：序号（自动递增）、章节标题输入框、视频上传区域（拖拽或点击上传，支持 mp4/webm）、时长（上传后自动读取）；章节支持拖拽排序
5. **假设** 管理员完成所有步骤并点击"发布"，**当** 课程状态从"草稿"变为"已发布"，**那么** 触发消息推送（调用消息模块），通知目标用户"新课程发布"

**验收场景**:

2. **假设** 管理员可以导出观看记录为 Excel，**当** 点击"导出"按钮，**那么** 生成包含所有观看记录的 xlsx 文件

### 用户故事 7 - 留言管理 (优先级: P3)

管理员在后台查看和管理课程留言，可删除不当留言、置顶优质留言。

**优先级理由**: 内容审核需求。

**独立测试**: 管理员删除一条留言后，前台该留言消失。

**验收场景**:

1. **假设** 管理员在课程详情的"留言管理"tab中，**当** 查看留言列表，**那么** 显示留言人头像、姓名、内容摘要、时间、操作按钮（置顶/删除）
2. **假设** 管理员点击"置顶"，**当** 操作成功，**那么** 该留言在前台留言列表中置顶显示，标注"置顶"标签

---

### 边界情况

- 视频上传中断：支持断点续传，上传进度条实时显示
- 视频格式不支持：上传前校验格式，仅允许 mp4/webm
- 视频文件过大（>500MB）：提示用户压缩或分段
- 课程发布后不可修改为草稿：需先下架再编辑
- Markdown 内容含 XSS 攻击代码：markdown-it 配置 `html: false, linkify: true` 防注入
- 留言内容审核：留言提交后自动过滤敏感词

## 需求 *(必填)*

### 功能需求

- **FR-001**: 前台培训首页必须支持课程卡片网格/单列自适应布局、分类tab筛选、搜索、下拉刷新、上拉加载
- **FR-002**: 视频课程详情页必须支持多章节切换播放、单视频模式、课程简介/章节目录/附件/留言 tab
- **FR-003**: 文章课程详情页必须使用 `MarkdownViewer.vue`（markdown-it + toc 目录导航），PC端左侧悬浮目录，H5端顶部折叠目录
- **FR-004**: 系统必须自动记录视频播放进度（5秒间隔保存），支持恢复播放位置
- **FR-005**: 系统必须在文章滚动到底部时自动标记"已阅读"
- **FR-006**: 后台课程编辑页必须采用步骤导航（基本信息→章节管理→附件上传→可见性设置）
- **FR-007**: 章节管理必须支持拖拽排序、视频上传（进度条）、自动读取时长
- **FR-008**: 课程发布成功后必须自动触发消息模块推送通知
- **FR-009**: 后台必须支持查看课程观看记录，支持导出 Excel
- **FR-010**: 所有课程数据必须通过 `tenantFilter` 中间件进行租户过滤和可见性计算
- **FR-011**: 留言功能必须使用全局 `CommentSection.vue` 组件，支持回复和点赞
- **FR-012**: 附件功能必须使用全局 `AttachmentUploader.vue` 和 `AttachmentList.vue` 组件

### 关键实体

- **xc-courses-category（课程分类表）**: `_id`、`name`、`parent_id`、`sort_num`、`status`、`tenant_id`、通用字段
- **xc-courses（课程表）**: `_id`、`title`（标题）、`cover`（封面图URL）、`course_type`（video/article）、`summary`（简介，Markdown格式）、`content`（文章内容，article类型）、`category_id`（分类ID）、`status`（0=草稿/1=发布/2=下架）、`view_count`（观看人数）、`visibility`、`target_dept_ids`、`target_user_ids`、`tenant_id`、`created_by`、通用字段
- **xc-course-chapters（章节表）**: `_id`、`course_id`（课程ID）、`title`（章节标题）、`video_url`（视频URL）、`duration`（时长秒数）、`sort_num`（排序号）、`tenant_id`
- **xc-course-comments（留言表）**: `_id`、`target_type`（固定为 "training"）、`target_id`（课程ID）、`user_id`、`content`、`parent_id`（回复的留言ID）、`is_top`（是否置顶）、`like_count`（点赞数）、`tenant_id`、通用字段
- **xc-course-views（观看记录表）**: `_id`、`course_id`、`user_id`、`chapter_id`（当前章节）、`play_duration`（播放时长秒）、`progress`（进度百分比 0-100）、`is_completed`（是否完成）、`last_position`（上次播放位置秒）、`tenant_id`、通用字段
- **xc-course-attachments（附件表）**: 使用通用附件字段约定（`name`, `url`, `size`, `type`, `upload_time`），内嵌在 `xc-courses.attachments` 数组中
