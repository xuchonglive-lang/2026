# 办公应用平台 - 完整需求文档
# 技术栈：Vue 2 + VK UniCloud Router + UniCloud(阿里云) + Tailwind CSS + ShadCN UI
# 前台(xc)：所有页面均实现PC+H5自适应 | 后台(xc-admin)：PC Web管理端
# 云函数根路径：xc/uniCloud-aliyun/cloudfunctions/router/service

## 1. 租户管理系统需求

- 功能描述：以部门为租户单位的多租户数据隔离系统，确保每个部门用户只能看到本部门数据及上级部门指定的公共/定向信息，超级管理员可切换部门视角查看。
- 端侧功能（C端/前台）：
  1. 用户登录后自动加载所属租户（部门）上下文，所有业务数据自动按租户过滤，无需用户手动选择
  2. 页面顶部显示当前所属部门名称，无切换入口（普通用户固定绑定一个租户）
  3. 可查看上级部门发布的公共信息（visibility=public）和定向到本部门的信息（visibility=targeted, targetDepts含本部门ID）
  4. 不可跨部门浏览任何信息，接口层强制租户隔离校验
- 管理功能（B端/后台）：
  1. 部门（租户）CRUD管理：部门名称、部门编码、上级部门（树形结构）、部门负责人、排序号、状态（启用/停用），左侧树形部门导航+右侧部门详情表单
  2. 部门树形结构展示：支持无限层级，拖拽排序，展开/折叠，搜索过滤
  3. 部门成员管理：在部门详情页查看/添加/移除成员，一个用户只能归属一个部门
  4. 超级管理员专属功能：顶部下拉选择器切换当前操作部门，切换后所有业务页面数据按选中部门过滤，不可混合查看多部门数据
  5. 数据可见性配置：每条业务数据可设置 public（所有部门可见）、private（仅本部门可见）、targeted（指定下级部门可见，可多选）
- 权限约束：
  1. 普通用户：只能查看本部门数据+上级公共/定向数据，无部门管理权限
  2. 超级管理员：可管理所有部门，可切换部门视角，但每次只能查看一个部门的数据
- 技术组件：
  - 部门树组件：el-tree（后台）/ 自定义树组件（前台）
  - 部门选择器：el-cascader 级联选择器（后台顶栏）
- 路径/配置约束：
  - 后台部门管理页面：xc-admin/pages_plugs/system/dept/list.vue
  - 前台部门信息展示：xc/pages_plugs/system/dept/info.vue
  - 后台云函数：service/admin/system/dept/
  - 前台云函数：service/user/kh/dept/
  - 数据库集合：xc-tenants（租户/部门表）
  - uni-id-users 扩展字段：tenant_id（所属租户ID）、dept_path（部门层级路径）

## 2. 用户管理需求

- 功能描述：基于微信服务号的用户注册与多端登录系统，用户信息绑定微信基本信息和组织信息，开发阶段支持账密登录。
- 端侧功能（C端/前台）：
  1. H5端登录：微信服务号OAuth2.0授权登录，未注册用户自动创建账号并绑定微信openid/unionid
  2. PC端登录：微信扫码登录（生成带参二维码，微信扫码后服务号推送事件，完成登录）
  3. 开发模式登录：用户名+密码表单登录，登录页提供切换按钮（仅开发环境显示）
  4. 首次登录补全信息：弹窗引导用户填写真实姓名、选择所属部门（需管理员审批或邀请码机制）
  5. 个人信息页：显示微信头像、微信昵称、真实姓名、手机号、所属部门、角色，支持修改真实姓名和手机号
  6. 登录状态管理：token自动刷新，过期自动跳转登录页，多端登录互不冲突
- 管理功能（B端/后台）：
  1. 用户列表：表格展示（头像、微信昵称、真实姓名、手机号、部门、角色、状态、注册时间），支持按部门筛选（左侧部门树）、按姓名/手机号搜索、按状态筛选
  2. 用户详情/编辑：查看完整用户信息，可修改部门归属、角色分配、状态（启用/禁用/冻结），可审批新注册用户，是否具备系统登录权限。
  3. 用户创建（仅开发阶段）：手动创建用户并设置密码，正式环境仅通过微信授权注册
  4. 批量操作：批量启用/禁用/删除用户，批量分配角色
  5. 用户操作日志：查看用户登录历史、操作记录
- 权限约束：
  1. 普通用户：只能查看和编辑自己的个人信息
  2. 部门管理员：可查看本部门用户列表，可分配本部门角色
  3. 超级管理员：可管理所有部门用户，可跨部门调整用户归属
- 技术组件：
  - 微信授权组件：微信JS-SDK / 服务号OAuth
  - 扫码登录组件：自定义二维码生成+长轮询/WebSocket
  - 用户列表：vk-data-table（后台）
- 路径/配置约束：
  - 前台登录页：xc/pages/login/index.vue
  - 前台个人信息页：xc/pages_plugs/user-center/profile.vue
  - 后台用户管理页：xc-admin/pages_plugs/system/user/listforsystem.vue（借鉴xc-admin/pages_plugs/system/user/list.vue，在此基础上扩展，不修改原有的页面结构及功能）
  - 登录云函数：service/user/pub/loginByWeixin.js、service/user/pub/loginByPassword.js
  - 微信扫码云函数：service/user/pub/weixinScanLogin.js
  - 数据库：uni-id-users（扩展字段：real_name、tenant_id、wx_openid、wx_unionid、wx_avatar、wx_nickname）

## 3. 用户权限管理需求

- 功能描述：基于RBAC模型的权限管理，用户绑定租户后分配角色，角色关联后台菜单权限、功能操作权限和前台操作权限。
- 端侧功能（C端/前台）：
  1. 前台根据用户角色查询可见的培训内容。
  2. 前台操作按钮级权限控制：通过自定义指令 v-has-perm="'perm:code'" 控制按钮/操作的显示，自定义指令可参考用户登录信息中的$user对象中的permission: []数组，做一个判断。
  3. 无权限时显示友好提示页（403页面），不暴露功能入口
- 管理功能（B端/后台）：
  1. 角色管理：（已有）
  2. 菜单管理（已有）
  3. 权限分配：在用户详情页为用户分配角色（多选），角色自动继承菜单和操作权限
  4. 左侧导航菜单根据当前登录用户角色动态渲染，无权限菜单不显示（已有）
  5. 接口级权限校验：云函数中间件根据用户角色+权限标识校验请求权限（已有）
- 权限约束：
  1. 普通用户：只能使用被角色授权的功能
  2. 部门管理员：可为本部门用户分配本部门范围内的角色
  3. 超级管理员：可管理所有角色和权限，可为任何用户分配任何角色
- 技术组件：
  - 权限树组件：（已有）
  - 权限指令：自定义 Vue 指令 v-has-perm，自定义指令可参考用户登录信息中的$user对象中的permission: []数组，做一个判断。
- 路径/配置约束：
  - 后台角色管理页：xc-admin/pages_plugs/system/role/list.vue（已有）
  - 后台菜单管理页：xc-admin/pages_plugs/system/menu/list.vue（已有）
  - 后台权限管理页：xc-admin/pages_plugs/system/permission/list.vue（已有）
  - 角色云函数：service/admin/system/role（已有）
  - 数据库：uni-id-roles（已有）

## 4. 消息管理系统需求

- 功能描述：基于微信服务号模板消息的推送系统，业务模块触发消息推送，所有消息在数据库留存记录，支持按类型查询历史。
- 端侧功能（C端/前台）：
  1. 消息中心入口：首页右上角消息铃铛图标+未读数角标，点击进入消息列表页
  2. 消息列表页：顶部tab切换消息类型（系统通知/培训通知/工作通知/信息共享/全部），列表按时间倒序，每条显示标题、摘要、时间、已读/未读状态
  3. 消息详情页：显示完整消息内容，关联业务跳转按钮（如点击"查看培训课程"跳转到对应课程页）
  4. 标记已读：点击消息自动标记已读，支持一键全部标记已读
  5. 微信服务号推送：业务操作触发后通过微信模板消息推送到用户微信，消息内容含标题+摘要+操作人+时间+详情链接
- 管理功能（B端/后台）：
  1. 消息模板管理：配置各业务模块的消息模板（模板ID、标题模板、内容模板、跳转URL模板），绑定微信服务号模板消息ID
  2. 消息发送记录：按时间、类型、发送人、接收人、状态（成功/失败）筛选查询，表格展示发送详情
  3. 手动消息推送：管理员可手动编辑消息内容，选择推送目标（指定用户/指定部门/全体），预览后发送
  4. 消息统计：各类型消息发送量、送达率、阅读率的统计图表
  5. 微信服务号菜单管理：配置微信服务号的菜单，界面要模拟手机微信服务号界面，做到实时显示
  6. 微信服务号配置：配置 AppID、AppSecret、服务号Token、消息模板映射
- 权限约束：
  1. 普通用户：只能查看自己收到的消息和自己发出的消息记录
  2. 超级管理员：可查看所有消息记录，可管理消息模板，可手动推送消息，只有超级管理员才能配置微信服务号菜单、微信服务号配置
- 技术组件：
  - 消息列表组件：自定义 MessageList.vue（前台）
  - 消息角标组件：自定义 BadgeIcon.vue（前台）
  - 微信推送服务：wx-server-sdk / 自封装微信API调用
- 路径/配置约束：
  - 前台消息中心页：xc/page/message/list.vue
  - 前台消息详情页：xc/page/message/detail.vue
  - 后台消息管理页：xc-admin/pages/message/list.vue
  - 后台消息模板页：xc-admin/pages/message/template.vue
  - 后台微信菜单管理页：xc-admin/pages/message/wx-menu.vue
  - 后台微信配置页：xc-admin/pages/message/wx-config.vue
  - 消息云函数目录：service/admin/message/（后台管理）、service/client/message/（前台查询）
  - 微信服务号功能函数目录：service/admin/wx-push/（微信推送服务，消息推送云函数，含微信服务号的各类模块函数，包括获取access_token、微信确认服务checkWxService、消息转换formatMsg、菜单数据获取getMenuData、更新updateMenuData、删除deleteMenuData、菜单数据转换menuDataConvert等等）
  - 数据库集合：xc-messages（消息记录表）、xc-message-templates（消息模板表）、xc-wx-config（微信配置表）

## 5. 培训业务模块需求

- 功能描述：要符合租户管理规定，部门向本部门及下级部门用户发布培训课件（视频课程/文章课程），支持章节管理、附件、留言互动和观看记录，课程可设为公共或定向可见。
- 端侧功能（C端/前台）：
  1. 培训首页：顶部搜索栏+分类tab（全部/视频课程/文章课程/我的课程），下方课程卡片网格列表（封面图、标题、发布部门、观看人数、时长/字数），支持下拉刷新+上拉加载
  2. 视频课程详情页：顶部视频播放器（支持章节切换，左侧章节列表+右侧播放区域），视频下方显示课程标题、发布部门、发布时间、观看次数；再下方tab切换（课程简介/章节目录/附件下载/留言互动）
  3. 文章课程详情页：左侧悬浮目录导航组件（markdown-it-toc-done-right），右侧文章正文（markdown-it渲染），文章下方附件栏+用户浏览记录（history-manager-component浏览记录组件）+留言互动区（Artalk组件）
  4. 留言互动区：支持文字留言，按时间倒序展示，显示留言人头像+姓名+时间+内容，支持回复和点赞（Artalk组件）
  5. 课程观看记录：自动记录用户观看进度（视频记录播放时长和进度百分比，文章记录是否已阅读），"我的课程"中显示学习进度
  6. 权限控制：公共课程所有用户可见，定向课程仅授权用户/部门可见，无权限用户不显示该课程
- 管理功能（B端/后台）：
  1. 课程分类：课程的类别管理，支持多级分类。
  2. 课程列表：表格展示（标题、分类、发布部门、状态、观看人数、创建时间），支持按分类/状态/部门筛选，支持搜索
  3. 创建/编辑视频课程：基本信息表单（标题、封面、简介、分类）；章节管理（拖拽排序，每章节上传视频文件+标题+时长）；单视频模式（仅一个视频）；附件上传（多文件）；可见性设置（公共/定向+目标部门多选/目标用户多选）
  4. 创建/编辑文章课程：基本信息表单；Markdown编辑器编写文章内容；附件上传；可见性设置
  5. 课程状态管理：草稿→发布→下架，发布时触发消息推送
  6. 观看记录查看：课程详情中查看观看用户列表（用户名、部门、观看时间、进度）
  7. 留言管理：查看/删除留言，可置顶留言
- 权限约束：
  1. 普通用户：只能查看有权限的课程，可留言互动
  2. 部门管理员：可发布本部门课程，可设置定向到下级部门
  3. 超级管理员：可管理所有部门课程
- 技术组件：
  - Markdown渲染：markdown-it + markdown-it-toc-done-right（目录导航）
  - 视频播放器：Video.js播放器组件
  - 富文本编辑器：cherry-markdown编辑器组件（后台）
  - 文件上传：阿里云OSS上传组件（可使用vk-unicloud-admin自带组件）
  - 用户浏览记录：history-manager-component浏览记录组件
  - 留言回复系统：Artalk组件
- 路径/配置约束：
  - 前台培训首页：xc/pages/training/list.vue
  - 前台视频课程详情：xc/pages/training/video-detail.vue
  - 前台文章课程详情：xc/pages/training/article-detail.vue
  - 后台课程分类管理：xc-admin/pages/training/category.vue
  - 后台课程管理：xc-admin/pages/training/list.vue
  - 后台课程编辑：xc-admin/pages/training/edit.vue
  - 后台云函数目录：service/admin/training/
  - 前台云函数目录：service/client/training/
  - 数据库集合：xc-courses-category（课程分类表）xc-courses（课程表）、xc-course-chapters（章节表）、xc-course-comments（留言表）、xc-course-views（观看记录表）、xc-course-attachments（附件表）

## 7. 重点工作推进模块需求

- 功能描述：要符合租户管理规定，分为"重点任务"（互动型，含工作标准/过程反馈/验收）和"重点关注"（持续反馈型，发布人完成确认后不可再反馈），支持跨部门任务派发。
- 端侧功能（C端/前台）：
  1. 重点工作首页：上下两个部分，上部分重点关注（按分类分块，每个块采用卡片显示，有类型名字、重点关注标题列表+日期、更多），下部分为重点任务，顶部tab切换分类，每个分类按照工作集合分块显示，每个块内工作项目列表（手风琴），每项显示标题、状态标签（进行中/待验收/已完成）、承接人头像组、截止日期，点击后手风琴打开，其他的关闭，可以动态加载每项工作详情，可以剪辑查看详情，页面内容可以参考重点任务详情页。
  2. 重点关注列表页：上下两个部分，上面是检索部分，可根据时间间隔、工作类型、重点工作信息模糊搜索，下部分主要是重点关注列表，每个列表块显示标题、时间、类型、反馈次数、状态（执行中、已结束）。点击列表块将进入重点关注详情页。
  3. 重点任务详情页，（三段式布局）：
     - 第一部分-工作标题区：工作标题（大字），下方显示工作类型标签、发布人、发布时间、查看次数
     - 第二部分-工作标准区：富文本显示。
     - 第三部分-工作反馈区：按时间倒序展示反馈列表，每条反馈含：反馈人头像+姓名+时间+反馈类型标签（过程反馈/验收申请）+富文本内容；底部"提交反馈"按钮（弹窗：选择反馈类型+富文本编辑器（tiptap组件，支持图片复制粘贴上传）+附件上传）
  4. 工作验收操作（任务发布人专属）：验收申请类型的反馈下方显示"验收评价"按钮，点击弹窗填写验收评价内容+验收结果（通过/驳回）
  5. 重点关注详情页：同上三段式布局，但反馈区仅支持"过程反馈"，无验收流程；发布人可点击"完成确认"按钮结束该项工作，结束后反馈区显示"已完成"标识，不可再提交反馈
  6. 承接人选择：支持选择本部门一个或多个用户，或下级部门的一个或多个用户
- 管理功能（B端/后台）：
  1. 工作分类管理：增删改查工作分类，仅支持2级
  2. 工作集合管理：增删改查工作分类，工作集合要隶属于工作分类（新增 / 修改用 Select 选择器关联分类数据）
  3. 重点任务列表：表格展示（标题、类型、发布人、承接人、状态、创建时间），按类型/状态/部门筛选（新增 / 修改用 Cascader 级联选择器关联分类 / 集合，集合仅显示无重点工作或未完成的，全部完成的不做显示）
  4. 创建/编辑重点任务：基本信息表单（标题、工作类型、工作集合，新增 / 修改用 Cascader 级联选择器关联分类 / 集合，集合仅显示无重点工作或未完成的，全部完成的不做显示）；工作标准编辑（custom-editor-tinymce组件）；附件上传；承接人选择（本部门/下级部门用户多选）；可见性设置
  5. 创建/编辑重点关注：同上，但无验收流程配置
  6. 工作反馈管理：查看所有反馈记录，可删除不当反馈
  7. 验收管理：查看待验收列表，执行验收操作
  8. 工作统计：按部门/人员/状态统计工作完成情况
- 权限约束：
  1. 普通用户：查看分配给自己的任务，提交反馈
  2. 任务发布人：创建任务、执行验收
  3. 部门管理员：管理本部门工作
  4. 超级管理员：管理所有工作
- 技术组件：
  - Markdown渲染：markdown-it + markdown-it-toc-done-right
  - 后台富文本编辑器：custom-editor-tinymce组件，使用参考https://vkdoc.fsq.pub/admin/custom-components/components/custom-editor-tinymce.html
  - 用户多选组件：自定义 UserPicker.vue（支持跨部门选人）
  - 前台富文本编辑组件：tiptap组件（支持图片复制粘贴上传）
  - 选择组件：cascader、select，使用参考https://vkdoc.fsq.pub/admin/components/11%E3%80%81cascader.html、https://vkdoc.fsq.pub/admin/components/9%E3%80%81select.html
- 路径/配置约束：
  - 前台重点工作首页：xc/pages/key-work/list.vue
  - 前台关注列表：xc/pages/key-work/focus-list.vue
  - 前台任务详情：xc/pages/key-work/task-detail.vue
  - 前台关注详情：xc/pages/key-work/focus-detail.vue
  - 后台工作管理：xc-admin/pages/key-work/list.vue
  - 后台工作编辑：xc-admin/pages/key-work/edit.vue
  - 后台分类管理：xc-admin/pages/key-work/category.vue

  - 前台云函数目录：service/client/key-work/

## 8. 专业管理模块需求

- 功能描述：要符合租户管理规定，督促部门人员规范专业管理工作，包含制度文档管理、专业管理网络（组织结构图）、例行工作日历任务和个人文档管理四大子功能。
- 端侧功能（C端/前台）：
  1. 专业管理首页：顶部tab切换四个子模块（制度规范/管理网络/例行工作/我的文档）
  2. 制度规范子模块：按专业分项列表展示制度/规范文档，每项显示标题、发布部门、更新时间；点击进入文章详情页（markdown-it渲染+左侧目录导航）；本部门和下级部门对口专业（角色）用户可查看
  3. 管理网络子模块：职能组织结构图展示，顶部显示当前用户专业角色，向下展开对应下级各平行部门的对口专业（角色）用户卡片（头像+姓名+部门+职务）；上级用户可点击下级用户卡片，跳转至该用户的专业管理主页查看其制度文档和工作情况
  4. 例行工作子模块：FullCalendar日历组件，月/周/日三种视图切换；显示工作任务条目（不同颜色区分来源：自己添加=蓝色、部门领导分配=橙色、上级对口专业分配=红色）；点击任务条目弹窗显示任务详情（标题、内容、来源、状态、截止时间）；支持添加自己的工作任务；收到的任务需要完成反馈（文字+附件）；任务支持重复规则设置（每周重复/每月重复/自定义规则）

  5. 文档管理监控：查看各用户文档上传情况（仅统计，不可查看私有文档内容）
- 权限约束：
  1. 普通用户：查看本专业制度文档，管理自己的例行工作和文档
  2. 部门领导：可为本部门下级用户添加工作任务

## 9. AI信息分析模块需求（仅后台）

- 功能描述：要符合租户管理规定，用户配置AI分析项目（文档类型、API Key、提示词），上传文档后调用AI接口生成专业分析报告（PDF），仅后台使用。
- 管理功能（B端/后台）：
  1. AI项目列表：表格展示（项目名称、文档类型、AI模型、创建时间、分析次数），支持搜索和筛选
  2. 创建/编辑AI项目：项目名称、项目描述、接受的文档类型（PDF/Word/Excel/图片等多选）、AI服务配置（API地址、API Key、模型选择）、提示词模板编辑（支持变量插入如{{文档内容}}）、输出格式配置（PDF模板选择）
  3. 执行AI分析：选择已配置的AI项目→上传文档（支持批量）→预览提示词（自动将文档内容填入模板）→确认执行→显示分析进度→分析完成后生成PDF报告并自动上传到OSS
  4. 分析记录管理：按项目/时间/状态筛选分析历史，每条记录显示：原始文档、生成的PDF报告（可下载/预览）、分析耗时、token消耗
  5. API Key管理：加密存储，支持多个AI服务商配置，支持余额/用量查询
- 权限约束：
  1. 普通用户：无权限访问此模块
  2. 授权用户：可使用已配置的AI项目执行分析
  3. 超级管理员：可创建/编辑AI项目，管理API Key
- 技术组件：
  - 文档预览：PDF.js（PDF预览）
  - 提示词编辑器：自定义模板编辑器（支持变量高亮）
  - 文件上传：阿里云OSS多文件上传
  - AI接口调用：云函数封装HTTP请求
  - PDF生成：pdfkit 或 puppeteer（云函数中生成PDF）
- 路径/配置约束：
  - 后台AI项目列表：xc-admin/pages/ai-analysis/list.vue
  - 后台AI项目编辑：xc-admin/pages/ai-analysis/edit.vue
  - 后台AI执行分析：xc-admin/pages/ai-analysis/execute.vue
  - 后台分析记录：xc-admin/pages/ai-analysis/records.vue
  - 后台云函数：service/admin/ai-analysis/
  - 数据库集合：xc-ai-projects（AI项目表）、xc-ai-records（分析记录表）、xc-ai-api-keys（API Key表，加密存储）

## 11. 公共技术组件与约定

- 前端 CSS 框架（全局）：
  - 核心框架：Tailwind CSS + ShadCN UI
  - 适用范围：前台(xc)所有新增页面
  - 与已有 Sass 样式兼容共存

- 前端自适应布局组件（全局封装）：
  - AppLayout.vue：主布局容器（PC/H5 双模式自动切换）
  - TopNavBar.vue：顶部导航栏（PC 完整导航 / H5 简化标题栏）
  - DrawerMenu.vue：H5 抽屉式侧边菜单
  - BottomTabBar.vue：H5 底部 TabBar 导航
  - PageFooter.vue：PC 页面底部页脚
  - SideMenu.vue：PC 左侧二级菜单导航
  - 组件路径：xc/components/layout/

- Markdown渲染方案（全局复用）：
  - 渲染引擎：markdown-it
  - 目录导航：markdown-it-toc-done-right（左侧悬浮目录）

- 附件管理方案（全局复用）：
  - 存储：阿里云OSS
  - 上传组件：基于 vk-data-upload 封装 AttachmentUploader.vue
  - 附件展示组件：AttachmentList.vue（显示文件名、大小、下载按钮）
  - 数据库字段约定：attachments 数组字段，每项含 {name, url, size, type, upload_time}

- 留言互动方案（全局复用）：
  - 组件：Artalk组件
  - 数据库字段约定：独立留言集合，通过 target_type + target_id 关联业务数据

- 浏览记录方案（全局复用）：
  - 组件：history-manager-component 浏览记录组件
  - 适用模块：培训、信息共享

- 可见性控制方案（全局复用）：
  - 字段约定：visibility（public/private/targeted）、target_dept_ids（目标部门数组）、target_user_ids（目标用户数组）
  - 中间件封装：service/middleware/modules/tenantFilter.js（自动注入租户过滤条件）

- 数据库通用字段约定：
  - _id：主键
  - tenant_id：租户ID（必填）
  - created_by：创建人ID
  - created_at：创建时间（时间戳）
  - updated_by：更新人ID
  - updated_at：更新时间（时间戳）
  - status：状态（0=禁用/草稿，1=启用/发布，2=下架/归档）
  - is_deleted：软删除标记（false/true）
